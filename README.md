# Policy Atlas · LIVE 政策观察台

面向直播治理的独立政策研究项目：用地图与事件时间线，将监管进展转为 LIVE 场景、准备事项和实施节点。

- 40 条事件，23 个地区；支持主题、阶段、场景和优先级筛选。
- 每条事件保留官方来源、核验记录和行动卡。
- 公开版为研究快照，内容复核时间显示在首页。

## 本地运行

使用 Node.js 22.13+，运行 `npm install`、`npm run dev`。`npm run build` 生成 `docs/`，可用于 GitHub Pages。

## 研究方法

事实以政府、监管、议会及法院材料为依据；政策建议为独立分析。法律阶段与行动优先级分别记录。详细适用范围、来源和研究边界见网站。
